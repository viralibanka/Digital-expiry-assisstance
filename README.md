# 🛡️ ExpiryVault

ExpiryVault is an AI-powered inventory and expiry management system built using FastAPI, PostgreSQL, HTML, CSS, and JavaScript.

---

## Features

- User Registration & Login
- JWT Authentication
- Inventory Management
- Add/Edit/Delete Products
- Dashboard Statistics
- Expiry Alerts
- Notification Bell
- AI Assistant
- Search Products
- Category Filter
- Pie Chart & Bar Chart
- Excel Export
- PDF Export
- Dark Mode
- Responsive Design

---

## Technologies Used

Backend

- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication
- ReportLab
- OpenPyXL

Frontend

- HTML
- CSS
- JavaScript
- Chart.js

---

## Installation

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend

Open

```
login.html
```

in your browser.
